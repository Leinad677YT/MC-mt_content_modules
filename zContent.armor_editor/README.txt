The commands you may find useful are all the subcommands that fall into the autocompletion of
	> function custom_armor:user/
	> place template custom_armor:
as well as something like
	> kill @e[tag=custom_armor]
to delete every entity rekated to this tool.

This tool aims to help with repetitive work when creating armors, which means that you can do something as simple as take an already functional item, place it on the armor stands and edit how it looks without needing to worry about changing tabs and reloading continuously.

For an item -> loottable conversor you may also want to check out Misode's generators, if you get the /give command of the item you want you can then turn it into a loottable there (check the usage of F3 + I or things like that)

If you just want the rgb colors, set the sidebar display to the "rgb" score and look out for your nickname
